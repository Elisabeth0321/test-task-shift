# 🏢 Office processor

Приложение для обработки данных сотрудников и менеджеров.

---

## 📌 Используемые инструменты
- **Версия Java:** 17
- **Система сборки:** Gradle

## 📦 Используемые сторонние библиотеки
- **Lombok** (`org.projectlombok:lombok:1.18.30`)
   - Упрощает генерацию геттеров, сеттеров и конструкторов.
   - [Project Lombok](https://projectlombok.org/)

## 🚀 Запуск
  В папке с проектом находиться файл **input.txt**. Там уже есть некоторые записи, но при желании вы можете их изменить.

### В папке с проектом выполните команду
   ```sh
    java -jar .\build\libs\test-task-shift-1.0.jar --output=file --path=output.txt --sort=salary --order=desc
   ```
Эквивалентным будет вызов команды с такими аргументами:
  ```sh
    java -jar .\build\libs\test-task-shift-1.0.jar --o=file --p=output.txt --s=salary --order=desc
   ```

🔹 Параметры запуска:
  ``` 
    --output=file – указывает, что результат будет записан в файл
    --path=output.txt – имя выходного файла, он будет создан автоматически в папке с проектом
    --sort=salary - указывает, что сортировка сотрудников будет происходить по зарплате
    --order=desc - сортировка по убыванию
   ```
